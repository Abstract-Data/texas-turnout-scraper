# systematic-debugging

Use when encountering any bug, test failure, or unexpected behavior — before proposing fixes.

Especially relevant for: JSESSIONID session issues, cookie jar failures, CSV parse errors,
unexpected election type mappings, pacing/rate-limit issues.

Trigger phrases: "debug this", "something broke", "unexpected behavior", "test failing"
