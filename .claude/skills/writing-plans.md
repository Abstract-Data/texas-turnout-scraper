# writing-plans

Use **before touching any code** when you have a spec or requirements for a multi-step task.

Produces a structured implementation plan: files to create, files to touch, files not to touch,
risks, and sequencing. Required before `executing-plans`.

Trigger phrases: "write a plan", "plan this out", "before we implement", "spec this first"
