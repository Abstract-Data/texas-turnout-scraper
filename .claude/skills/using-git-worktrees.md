# using-git-worktrees

Use when starting feature work that needs isolation — creates a git worktree so you work on a
separate branch without disturbing the main checkout.

Required for this project: never commit to main directly.

Trigger phrases: "start a feature branch", "isolate this work", "new worktree", "feature branch"
