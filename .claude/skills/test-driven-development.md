# test-driven-development

Use when implementing **any feature or bugfix**, before writing implementation code.

Write the test first → confirm it fails → implement → confirm it passes.

For this project: use `respx` to mock httpx calls; fixtures in `tests/fixtures/early_voting/`.

Trigger phrases: "TDD", "test first", "write the test before", "implement with tests"
