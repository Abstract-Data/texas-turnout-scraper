# Security Policy

## Supported versions

Only the latest published release line is supported. Fixes ship on that line. When a newer release line is published, support moves to it and the previous line is unsupported.

| Version | Supported |
| --- | --- |
| Latest release line (currently 0.2.x; latest tag `texas-turnout-scraper-v0.2.3`) | Yes |
| Older release lines | No |
| Unreleased `main` | No |

## Reporting a vulnerability

Report suspected vulnerabilities through GitHub private vulnerability reporting:

1. Open this repository's **Security** tab.
2. Choose **Report a vulnerability**.

That form is private. Do not file a public issue for a suspected vulnerability.

Expected acknowledgement window: **3 business days**. A remediation timeline comes after the report is confirmed.

Include the affected version, what the issue is, and how to reproduce it. Do not include voter names or voter identification numbers.
